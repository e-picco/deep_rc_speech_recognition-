# deep_rc_speech_recognition-
Code accompanying the paper "Deep Photonic Reservoir Computer for Speech Recognition" [https://doi.org/10.1109/TNNLS.2024.3400451], written by E. Picco, A. Lupo, S. Massar, and published in IEEE TNNLS. 

The complete code to run experimentsis provided: Matlab scripts for the software interface, and VHDL code to program the Virtex-7 FPGA chip.
